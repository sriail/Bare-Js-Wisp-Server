# Web Crawler Plugin
A simple web scraper using the Bare Js wisp server

## Instructions

1: Add a seed file (rename the inbuilt example seed file, or upload your owen in the web interface)
2: Upload the crawler.js file into the src directory (along with the seed file if you added one!!!)
3: Confirm via the web interface (Use the web interface to start Crawling Pages)

# Note
This Plugin was developed by the same team who developed the bare js wisp server, and is tailored specifically to its integrated client
